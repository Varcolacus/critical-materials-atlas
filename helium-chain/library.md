# Helium chain — research library

The gas that cools MRI scanners cannot be manufactured — only captured: helium is a non-renewable by-product of a handful of helium-rich natural-gas fields in the US, Qatar and Russia, and once released it escapes to space. A curated reference library for deeper study — public sources, gathered August 2026. Each entry links to a real source.
