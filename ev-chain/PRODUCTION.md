# Production checklist

- [ ] Review motor-architecture language with an electric-machine specialist.
- [ ] Add model-level bills of materials only from a consistent audited source.
- [ ] Do not calculate mineral tonnes from vehicle counts without battery size and chemistry distributions.
- [ ] Review the HS17 clean-vehicle baskets and re-export effects.
- [ ] Add second-life and recycling flows only when comparable realised-flow data exist.
- [ ] Remove `noindex` and link from the live Atlas only after editorial approval.
